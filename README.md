# macOS Syscall Tracing, Call Graph & Optimization Tools

Набор утилит на C++ для анализа, визуализации и **автоматической оптимизации системных вызовов** на macOS с использованием DTrace API.

---

## 📌 Состав набора

1. **`syscall_optimizer`** — **Анализатор анти-паттернов и узких мест**. Автоматически находит небуферизованный В/В, memory thrashing, спам вызовами `stat` или опросами времени, рассчитывает **Syscall Efficiency Index (0-100%)** и дает точные стеки вызовов с рекомендациями по переписыванию алгоритма.
2. **`syscall_callgraph`** — Захватывает стек вызовов пользователей (`ustack`) и строит **обратное дерево вызовов (Reverse Call Graph)** в консоли (ASCII/Markdown/JSON/Graphviz DOT).
3. **`syscall_counter`** — Подсчитывает общее количество и процентное соотношение каждого типа системного вызова.
4. **`unbuffered_demo` & `buffered_demo`** — Неоптимизированная и оптимизированная версии программы для сравнения алгоритмов.
5. **`AvaloniaDemo`** — Демо-приложение на Avalonia UI (.NET 10).

## 🔍 Анти-паттерны, выявляемые `syscall_optimizer`

| Идентификатор | Анти-паттерн | Проблема в алгоритме | Рекомендация |
|---|---|---|---|
| **`UNBUFFERED_IO`** | Небуферизованный В/В | Чтение/запись по 1 байту в циклах (`read`/`write`) | Использовать буфер (`std::vector<char>`, `fread`/`fwrite`, `fstream`) |
| **`MEMORY_THRASHING`** | Частые аллокации ядра | Множественные `mmap`/`munmap`/`mprotect` | Внедрить Арена-Аллокатор (Memory Pool) |
| **`STAT_SPAM`** | Спам метаданными | Повторные `stat`/`fstatat` для одних и тех же файлов | Кешировать результаты VFS проверки |
| **`TIME_POLLING`** | Активное ожидание | Заспамливание ядра вызовами `gettimeofday`/`nanosleep` | Заменить busy-wait на Event-Driven архитектуру |

## 🚀 Форматы вывода

- `--json` — Валидный структурированный JSON для LLM и CI/CD.
- `--markdown` / `--llm` — Чистый формат Markdown для нейросетей.
- `--report` / `--tree` / `--table` — Консольный отчёт для человека.
